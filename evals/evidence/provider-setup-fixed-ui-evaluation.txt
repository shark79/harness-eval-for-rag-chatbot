Ticket TCK-1002

How do I connect my own OpenAI API key instead of using the built-in credits? I don't want to burn through my free trial too fast. -- Priya

Evaluated response

To use your own OpenAI API key instead of the built-in Dify credits, first install the OpenAI provider plugin if not already done. Then enter your OpenAI API key credentials in the provider setup, which typically requires the API key and, for Azure OpenAI, additional details like the resource endpoint URL and deployment name. Once your workspace supplies its own OpenAI key, calls to OpenAI models will be billed directly by OpenAI and will no longer consume your workspace's Dify message credits. This way, you can avoid using your free trial credits too quickly by bringing your own key.
