Ticket TCK-1011

I'm getting a 401 Unauthorized when I try to call the dataset API to upload a document, but the same key works fine for my chatbot app. What's going on? -- Sam

Evaluated response

The 401 Unauthorized error occurs because the key you are using for the dataset API is actually an app key, which only works for your chatbot app and not for dataset API calls. Dataset API keys and app API keys are not interchangeable. To upload a document to the dataset API, you need to create a dataset API key from the dataset's detail page under the Service API panel. Use that dataset key for your document upload requests to avoid the 401 error.
